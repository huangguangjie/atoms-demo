# 使用说明

> 本应用为类 Atoms 平台演示:用自然语言描述应用创意,智能体给出分步计划、流式生成代码,并在右侧实时预览可运行的应用。

## 1. 快速开始

1. 打开应用首页,在中央输入框描述创意,例如:
   - 「做一个记录阅读进度的小站」
   - 「帮我做一个番茄钟计时器」
   - 「生成一个咖啡品牌落地页」
2. 按回车或点击发送按钮,进入对话视图。
3. 观察智能体的三段式产出:**执行计划**(逐步打勾;计划由意图识别与布局规划产出,包含应用类型拆解、Flex/Grid 布局策略、间距/圆角等视觉规范与响应式安排)→ **代码生成**(进度实时推进)→ **应用预览**(右侧分栏内可直接操作)。
4. 生成期间发送按钮变为**停止**按钮,点击可随时中止。

## 2. 输入区控件

| 控件 | 说明 |
|------|------|
| ＋ 添加 | 下拉收纳三个入口:上传附件、# 引用(文件/位置/关键信息)、连接 MCP 工具(显示已连接数量) |
| 🎨 主题 | 选择配色主题,直接影响生成应用的色板 |
| 构建/目标 模式 | 构建模式=生成新应用;目标模式=面向结果迭代 |
| 🎙 语音 | 点击开始录音,再次点击结束;录音上传至平台转写服务(scribe_v2)后,文本自动填入输入框;转写服务不可用或浏览器不支持时自动回退浏览器原生识别 |
| 发送/停止 | 提交提示词;输入为空时置灰;生成中变为停止 |

输入区为大圆角卡片(上输入、下工具栏),欢迎页顶部公告条可关闭。

## 3. 应用预览面板

- 生成完成后右侧出现预览分栏,应用在 iframe 中**真实运行**(如待办应用可添加/勾选事项,数据保存在应用内 localStorage)。
- 顶部工具:**预览/代码** 标签切换(代码可查看完整源码)、**刷新**、**关闭**。
- 分栏边界可拖拽调整宽度。

## 4. MCP 连接

- 点击输入区左下角「+」按钮,在下拉菜单中选择「连接 MCP 工具」(菜单内会显示已连接数量)。
- 在弹窗中填写服务名称与远程 MCP 地址(如 `https://mcp.example.com/sse`),点击连接。
- 已连接服务持久保存在本机(localStorage),对话区会展示连接状态与已连接数量。

## 5. 工作区与会话

- 工作区是会话与项目的容器:侧边栏顶部的选择器显示当前工作区,下拉可切换;注册流程会通过数据库触发器自动创建默认工作区「<用户名> 的 Atoms」。
- 下拉菜单「新建工作区」输入名称即可创建,创建成功后自动切换为当前工作区;未登录时该项置灰,引导先登录。
- 「最近」列表只展示当前工作区的会话,切换工作区后列表随之过滤;点击「新会话」(或直接在首页发起对话)即进入当前工作区的新对话,新会话首次发送时归属当前工作区。
- 已登录但暂无工作区时,发起对话会被引导先创建工作区,避免会话无处归属。
- 生成完成后,应用自动创建为项目:出现在侧边栏「最近」与「我的项目」页。
- 侧边栏点击最近会话可**回放**当时的对话与生成结果。
- 「我的项目」页支持全部/已收藏切换与收藏操作。

## 6. 资源页

- **发现**:浏览社区应用,按分类过滤,卡片提供体验/克隆/魔改入口。
- **模板**:按分类浏览模板,点击「填写占位」打开占位填写弹窗:按字段(名称/标语/定价等)填入你的内容(留空保留默认值),确认后一键生成应用——占位内容真实替换进页面,并自动保存为项目可预览回放。首页底部「模板」快捷区点击模板卡片同样打开该弹窗。

## 7. 侧边栏

- 点击 Logo 或折叠按钮收起/展开;边界可拖拽调宽。
- 顶部工作区选择器切换工作区,下拉内提供「新建工作区」;底部为登录/用户入口、设置与通知;「最近」标题旁的「新会话」按钮在当前工作区开启新对话。
- 未登录时点击用户区可打开登录弹窗;已连接 Supabase 时,发起对话、克隆应用或填写模板生成前也会先要求登录。

## 8. 连接模式与演示模式

- Supabase 已连接时:注册/登录为真实账号,项目、会话、消息持久化到云端;注册时数据库触发器自动创建资料与默认工作区;智能体与语音转写调用平台 Edge Function(密钥仅在服务端)。写操作需要登录:未登录时先弹出登录框,不执行云端写入;接口或生成失败会显示真实错误提示,不静默回退演示数据。
- 未配置环境变量的本地预览运行于演示模式:所有数据保存在本浏览器,刷新即失;智能体使用内置生成管线,语音按钮回退浏览器原生识别。

## 9. 常见问题

**Q:切换工作区后,为什么「最近」里的会话不见了?**
A:侧边栏「最近」只显示当前工作区的会话;在顶部工作区选择器切回原工作区即可看到。会话按工作区隔离存储,互不影响。

**Q:生成的应用刷新首页后还在吗?**
A:在。项目与对话已持久化到 Supabase,登录同一账号刷新后仍可从「我的项目」与侧边栏最近对话回放(仅本地未配置 Supabase 时为内存演示数据)。

**Q:语音按钮没反应或转写失败?**
A:转写走平台服务(scribe_v2),需要登录且服务可用;服务不可用、未登录或浏览器不支持录音时,自动回退浏览器原生识别(Chrome/Edge 效果最好);两者都不可用时按钮会提示不支持。

**Q:为什么发起对话时提示登录?**
A:云端模式(已连接 Supabase)下对话、项目均归属真实账号,未登录时应用会先弹出登录框,避免以无效身份写库导致失败;登录后即可正常创建对话与生成应用。

**Q:生成或保存失败时为什么直接显示报错,而不是用演示内容兜底?**
A:云端模式下失败会被真实透出(如网络异常、服务不可用、登录过期),便于定位问题;仅本地未配置 Supabase 的演示模式才使用内置生成与本地数据。

**Q:生成的应用页面布局还会像以前一样乱跑吗?**
A:不会。智能体现在写代码前会先做意图识别与布局规划(应用类型、内容分区、Flex/Grid 策略、间距与圆角规范、响应式断点),生成时强制执行布局工程约束:页面级结构禁用绝对定位、多分区桌面横排且窄屏自动纵向堆叠、移动端适配必做;产物还会剥离多余文本,仅保留完整 HTML 文档,不会出现 Markdown 原始符号或说明性杂文。

**Q:预览里的应用可以操作吗?**
A:可以,iframe 内为真实运行的应用,交互数据保存在应用自身。

**Q:如何接入真实后端?**
A:在平台 UI 关联 Supabase 后建表(见 `docs/data-model.md`),前端配置环境变量即可自动切换,见 `docs/deployment.md`。
