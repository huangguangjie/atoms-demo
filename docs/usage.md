# 使用说明

> 本应用为类 Atoms 平台演示:用自然语言描述应用创意,智能体给出分步计划、流式生成代码,并在右侧实时预览可运行的应用。

## 1. 快速开始

1. 打开应用首页,在中央输入框描述创意,例如:
   - 「做一个记录阅读进度的小站」
   - 「帮我做一个番茄钟计时器」
   - 「生成一个咖啡品牌落地页」
2. 按回车或点击发送按钮,进入对话视图。
3. 观察智能体的三段式产出:**执行计划**(逐步打勾)→ **代码生成**(进度实时推进)→ **应用预览**(右侧分栏内可直接操作)。
4. 生成期间发送按钮变为**停止**按钮,点击可随时中止。

## 2. 输入区控件

| 控件 | 说明 |
|------|------|
| 📎 附件(+) | 添加附件(演示形态) |
| 🎨 主题 | 选择配色主题,直接影响生成应用的色板 |
| 构建/目标 模式 | 构建模式=生成新应用;目标模式=面向结果迭代 |
| # 引用 | 以 `#` 引用上下文/资源(演示形态) |
| 🎙 语音 | 点击开始录音,再次点击结束;录音上传至平台转写服务(scribe_v2)后,文本自动填入输入框;转写服务不可用或浏览器不支持时自动回退浏览器原生识别 |
| 发送/停止 | 提交提示词;生成中变为停止 |

## 3. 应用预览面板

- 生成完成后右侧出现预览分栏,应用在 iframe 中**真实运行**(如待办应用可添加/勾选事项,数据保存在应用内 localStorage)。
- 顶部工具:**预览/代码** 标签切换(代码可查看完整源码)、**刷新**、**关闭**。
- 分栏边界可拖拽调整宽度。

## 4. MCP 连接

- 点击输入区下方「将你的工具连接到 Atoms」。
- 在弹窗中填写服务名称与远程 MCP 地址(如 `https://mcp.example.com/sse`),点击连接。
- 已连接服务持久保存在本机(localStorage),对话区会展示连接状态与已连接数量。

## 5. 会话与项目联动

- 生成完成后,应用自动创建为项目:出现在侧边栏「最近」与「我的项目」页。
- 侧边栏点击最近会话可**回放**当时的对话与生成结果。
- 「我的项目」页支持全部/已收藏切换与收藏操作。

## 6. 资源页

- **发现**:浏览社区应用,按分类过滤,卡片提供体验/克隆/魔改入口。
- **模板**:按分类浏览模板,点击「填写占位」打开占位填写弹窗:按字段(名称/标语/定价等)填入你的内容(留空保留默认值),确认后一键生成应用——占位内容真实替换进页面,并自动保存为项目可预览回放。首页底部「模板」快捷区点击模板卡片同样打开该弹窗。

## 7. 侧边栏

- 点击 Logo 或折叠按钮收起/展开;边界可拖拽调宽。
- 顶部空间选择器切换空间;底部为登录/用户入口、设置与通知。
- 未登录时点击用户区可打开登录弹窗(演示模式无需注册)。

## 8. 连接模式与演示模式

- Supabase 已连接时:注册/登录为真实账号,项目、会话、消息持久化到云端;智能体与语音转写调用平台 Edge Function(密钥仅在服务端)。
- 未配置环境变量的本地预览运行于演示模式:所有数据保存在本浏览器,刷新即失;智能体使用内置生成管线,语音按钮回退浏览器原生识别。

## 9. 常见问题

**Q:生成的应用刷新首页后还在吗?**
A:在。项目与对话已持久化到 Supabase,登录同一账号刷新后仍可从「我的项目」与侧边栏最近对话回放(仅本地未配置 Supabase 时为内存演示数据)。

**Q:语音按钮没反应或转写失败?**
A:转写走平台服务(scribe_v2),需要登录且服务可用;服务不可用、未登录或浏览器不支持录音时,自动回退浏览器原生识别(Chrome/Edge 效果最好);两者都不可用时按钮会提示不支持。

**Q:预览里的应用可以操作吗?**
A:可以,iframe 内为真实运行的应用,交互数据保存在应用自身。

**Q:如何接入真实后端?**
A:在平台 UI 关联 Supabase 后建表(见 `docs/data-model.md`),前端配置环境变量即可自动切换,见 `docs/deployment.md`。
